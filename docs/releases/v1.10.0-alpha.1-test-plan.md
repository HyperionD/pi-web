# v1.10.0-alpha.1 手动测试计划

这是 JuunAI pi-web Fork 的首个公开预发行版本，目标是验证中文默认界面、离线单二进制、用户隔离、工作区操作和 Pi 会话主链路。

## 发布信息

- 版本：`v1.10.0-alpha.1`
- 仓库：`https://github.com/HyperionD/pi-web`
- 支持平台：Linux/macOS `amd64`、`arm64`
- 推荐浏览器：Chrome 107 或更高版本
- 测试模式：优先 `--mock`，再使用真实 Pi CLI

## 发布前门禁

在干净工作区执行：

```bash
bun install --frozen-lockfile
bun run lint
bun run typecheck
bun run test
bun run backend:test
bun run build:single
git diff --check
```

确认：

- `package.json`、CLI 输出和 release tag 都是 `v1.10.0-alpha.1`。
- `static/` 与当前前端构建一致。
- `dist/pi-web` 可执行，且不依赖 Node、Bun 或动态前端服务。
- GitHub Release 标记为 Pre-release，包含对应平台压缩包。

## 安装与启动

下载对应平台压缩包并校验 SHA256：

```bash
sha256sum -c SHA256SUMS
./pi-web --host 127.0.0.1 --port 8732 --mock
curl -fsS http://127.0.0.1:8732/api/health
```

真实 Pi 模式：

```bash
command -v pi
pi --version
./pi-web --host 127.0.0.1 --port 8732
```

## 测试矩阵

| 编号 | 用例 | 预期 |
| --- | --- | --- |
| A-001 | 首次打开并设置管理员密码 | 中文登录页正常显示，管理员创建成功 |
| A-002 | 退出后重新登录 | HttpOnly cookie 生效，未登录不能访问受保护数据 |
| A-003 | 添加两个工作区 | 文件树和会话列表与目录对应 |
| A-004 | 创建普通用户并只授权一个工作区 | 普通用户无法看到或访问未授权工作区 |
| A-005 | mock 模式发送中文 Prompt | 流式响应只出现一次，最终状态恢复 idle |
| A-006 | 连续发送两条 Prompt | 顺序正确，不发生跨请求或跨 session 串流 |
| A-007 | 刷新正在运行的 session | 历史消息恢复，SSE 不重复消息 |
| A-008 | 短暂断网后恢复 | 自动重连，事件和工具输出不重复、不丢失 |
| A-009 | 编辑并保存文件 | 内容写入工作区，刷新后仍保持 |
| A-010 | 附件和上传大小限制 | 超限请求被明确拒绝，正常文件可用 |
| A-011 | 中文、emoji、Markdown 和特殊文件名 | 文本按文字显示，不执行 HTML/脚本 |
| A-012 | 停止并重启二进制 | 数据库、账号、工作区和 session 可恢复 |
| A-013 | 真实 Pi Prompt | 记录 Pi 版本、provider/auth 状态和结果 |
| A-014 | CLI 版本命令 | `pi-web version` 输出 `pi-web v1.10.0-alpha.1` |
